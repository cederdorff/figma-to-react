What is Motion?

React animation library (formerly Framer Motion)

  • Production-grade UI animation for React apps.
  • Start simple: prop-based animation. Scale to layout, gestures and scroll.
  • Hybrid engine: native browser animations first, JavaScript fallback for advanced behavior.
  • Trusted in products from Framer and Figma with 30M+ monthly downloads on npm.

Why Motion for React?

Why use it in this course?

  • State changes become visible and clear.
  • Interactions feel more responsive (tap, hover, drag, scroll).
  • Faster prototyping directly in React code.
  • Fits Figma workflows: Figma Sites and Figma Make can produce Motion-based animation/code.
  • One approach from micro-feedback to complex flows.

Motion Key Advantages

Key advantages

When it is the right choice

  • React-first: state + props drive animation directly.
  • Fast: smooth performance by default.
  • Flexible: one API for simple and advanced cases.
  • Cross-device gestures: reliable tap, drag and hover.
  • Production-ready: typed, tested, tree-shakable.

What is Haptic Feedback?

  • Haptics = tactile feedback (small vibrations).
  • Useful for success, warning and error feedback.
  • Best when it supports meaning, not decoration.

Why use it? A second feedback channel next to visuals and motion.
