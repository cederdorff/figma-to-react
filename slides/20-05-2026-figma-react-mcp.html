React Before MCP

Why React knowledge still matters

If you only prompt

  • You may get code you cannot explain.
  • You may keep duplicated or overly literal components.
  • You may miss where state and interaction should live.
  • You may accept a static screen instead of a prototype.

If you understand React

  • You can read the component structure critically.
  • You can decide what to keep, split, rename or rebuild.
  • You can place props, state and events more intentionally.
  • You can turn generated output into something more believable.

MCP Framing

What is Figma MCP actually doing?

A useful mental model

Think of Figma MCP as a bridge that gives the AI tool more design context: components, layers, variables, spacing and structure.

The AI tool still generates the code. MCP helps the tool see more of the design.

Important consequence

  • MCP is not a guarantee of good code.
  • Good design context still needs good judgement.
  • Generated output still needs reading, critique and refactoring.

Exercise Time

From scaffold to prototype

Your task

  • Use the Figma MCP Starter Guide.
  • Set up Figma MCP with VS Code.
  • Start from a Figma design.
  • Use MCP/AI to get a first React scaffold.
  • Refactor at least one part of the structure.
  • Add at least one meaningful interaction.
  • If there is time, let someone else try a short task.

Possible flows

  • Overview to detail to action
  • Onboarding to choice to result
  • Product selection to confirmation
  • Physical object or location to digital content to saved choice

Use the Codeagram app from last lesson as your React reference when you inspect and improve the generated code.

Exercise Checklist

What should you improve after generation?

Structure

  • Are the component names clear?
  • Is anything too big or too repeated?
  • Should some values become props?

Interaction

  • What state is missing?
  • What should react to user input?
  • What feedback should appear after an action?

Prototype quality

  • If someone else tries it, can they understand the flow?
  • Does the prototype feel believable?
  • What should be rebuilt instead of patched?
