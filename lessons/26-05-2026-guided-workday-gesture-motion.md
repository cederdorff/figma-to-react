## Optional Guided Workday - Gesture & Motion Preparation

### Purpose of The Day

This day is an optional guided workday. I will be available in the room if you want help, feedback or a place to work with your current tasks.

You decide whether you want to attend in person. Everyone will be registered as present.

The planned lesson content for today, **Touch Gestures as Interface**, has been moved to **29-05-2026**. The [original May 26 lesson page](26-05-2026-touch-gestures-interface.md) is still available for reference.

Use the day to catch up, strengthen your React foundation, continue your prototype or prepare for the upcoming gesture and motion work.

By the end of the workday, you should have made progress on a task that fits your current level and know what you want to bring into the next lesson.

### Suggested Tasks

Choose the level that fits where you are right now. You can move between levels during the day.

#### Level 1 - Catch Up and Strengthen the Basics

Use this track if React, components, props, state or events still feel unclear.

- Work through [Getting started with React](https://race.notion.site/Getting-started-with-React-0fd48b8ae90a438bb6ec8dc95628f13f).
- Continue the [CodeDex React course](https://www.codedex.io/react).
- Revisit JSX, components, props, state and events on [React.dev Learn](https://react.dev/learn).
- Continue or clean up your Codeagram app.
- Make sure you can explain what each main component in your app does.

#### Level 2 - Practise Components and Layout

Use this track if you understand the basics and want a practical React build.

- Build the [React Page Layout with Components](https://github.com/cederdorff/react-vite-page-layout/blob/main/docs/EXERCISE_GUIDE.md).
- Build the [Codeagram Feed with React Components](https://github.com/cederdorff/codeagram/blob/main/docs/EXERCISE_GUIDE.md) if you want a more app-like component exercise.
- Create clear component files and connect them in `App.jsx`.
- Practise using `className`, CSS and responsive layout.
- Check that your app still works after each small step.

#### Level 3 - Work with Data and State

Use this track if you want to practise dynamic React apps.

- Build the [React User List App](https://race.notion.site/React-User-List-App-53509f089e9f43e08857f0331775329d).
- Continue with the [React User CRUD App](https://race.notion.site/React-User-CRUD-App-c5eb67a692dc4734a813bdcdd2040eb7) if you are ready for forms and editing.
- Focus on state, events, lists and user interaction.
- Test each action carefully: create, read, update and delete.

#### Level 4 - Continue Your Figma to React Prototype

Use this track if you already have a Figma-to-React prototype started.

- Continue working with the [Figma MCP Starter Guide](https://github.com/cederdorff/figma-to-react/blob/main/guides/figma-mcp-starter-guide.md).
- Refactor generated code into clearer React components.
- Add state, events or simple interactions to make the prototype feel less static.
- Improve layout, naming, structure and visual consistency.

#### Level 5 - Prepare for Touch Gestures

Use this track if you are ready to prepare for the moved lesson on `29-05-2026`.

- Skim the [Motion for React docs](https://motion.dev/docs/react).
- Try adding `motion.div`, `whileHover` or `whileTap` to a small component.
- Build a very small draggable card, image, panel or button.
- Think about where a gesture could make your own prototype more meaningful.

#### Level 6 - Challenge Track

Use this track if you are comfortable working independently and want to push your prototype further.

- Build or extend the [React Router SPA](https://github.com/cederdorff/react-vite-spa/blob/main/react-router-spa.md).
- Design one touch, pointer, drag or swipe interaction for your own case.
- Decide what should happen before, during and after the gesture.
- Add feedback for selected, moved, accepted, rejected or completed states.
- Be ready to explain why the gesture improves the experience.
