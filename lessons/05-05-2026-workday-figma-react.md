## Workday - Figma to React

### Purpose of The Day

The purpose of this workday is to help you build confidence with the material from the first lesson.

Your main focus is to keep working with the tools, concepts and exercises from day one until they feel more familiar. This is not about rushing ahead. It is about making sure the foundation is in place before we continue.

By the end of the workday, you should be in a stronger position to follow the next React session and continue the move from design thinking to interactive code.

Part of the workday is also to prepare for the next lesson with LYDA. The details for that preparation will be available in Canvas.

---

### What To Do

1. **Go back to the materials from the first lesson**
   - Review the slides, examples and notes from `Figma to React: Intro, Tools & React`.
2. **Finish the exercises from day one**
   - Complete the exercises you started in the lesson.
3. **Review your setup and try to understand it better**
   - Make sure you understand what the different tools are for and that the basic workflow still works on your machine.
4. **Use the self-study guide if you need more support**
   - If HTML, CSS or JavaScript still feel shaky, start working through the self-study guide:
     https://www.notion.so/Self-study-with-CodeDex-io-350bc239db1180af9beacc9a801f863a
5. **Continue with the CodeDex React course**
   - When you are ready, continue with the React course here:
     https://www.codedex.io/react
6. **Prepare for the next lesson with LYDA**
   - The exact preparation for LYDA's lesson will be described in Canvas.

---

### Recommended Order

1. Finish the lesson-one exercises first.
2. Use the self-study guide if you need more support with HTML, CSS or JavaScript.
3. Continue with the CodeDex React course after that.
4. Check Canvas and prepare for the next lesson with LYDA.
