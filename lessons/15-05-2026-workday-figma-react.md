## Workday - Figma to React

### Purpose of The Day

This workday is for continuing the React work from the recent Figma to React sessions.

Your main focus is to keep developing the Codeagram app and strengthen your understanding of components, JSX, props, state and events through practice.

By the end of the workday, you should have made further progress on the app, improved your React confidence, continued with the self-study material or the CodeDex React course if needed, and taken care of practical preparation such as the GitHub Student Developer Pack.

---

### Main Focus

1. **Continue working on the Codeagram app**
   - Use the Codeagram exercise as your main practical task.
   - Keep working with layout, repeated UI, component structure, props, state and events.
2. **Improve the structure of your React code**
   - Decide what should stay inside one component and what should be split into smaller parts.
   - Keep improving naming, reuse and clarity.
3. **Strengthen the React basics**
   - Revisit the examples and ideas from the lesson when needed.
   - Make sure you understand how JSX, components, props, state and events connect in your code.
4. **Use support material when needed**
   - If HTML, CSS or JavaScript still feel shaky, continue with the self-study guide.
   - If React still feels new, continue with the CodeDex React course.
5. **Take care of the practical preparation**
   - Apply for the GitHub Student Developer Pack if you have not already done it.

---

### Recommended Order

1. Continue building the Codeagram app first.
2. Refine your component structure and clean up the code as you go.
3. Use the self-study guide if you need more support with HTML, CSS or JavaScript.
4. Continue with the CodeDex React course after that.
5. Apply for the GitHub Student Developer Pack if you still need to do it.

---

### If You Get Stuck

- Go back to the lesson notes and examples from `Figma to React: From Components to Composition`.
- Check whether the problem is about HTML/CSS/JavaScript basics, React basics or component structure.
- Ask for help if you are blocked for too long.
- You are welcome to write to me on Teams or by email at `race@eaaa.dk`.
- You are also welcome to use tools such as Claude, ChatGPT, Copilot and similar AI tools as study support.

### Suggested Checkpoints

Use these questions to decide whether you are moving in the right direction:

2. Can you point to where props are used and what they change?
3. Can you point to where state changes and what UI it affects?
4. Can you point to where events happen and what code they trigger?
5. Is your Codeagram app becoming easier to read and improve?
