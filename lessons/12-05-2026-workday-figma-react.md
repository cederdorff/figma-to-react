## Workday - Figma to React

### Purpose of The Day

This workday is for continuing the React work from the last lesson.

Your main focus is to keep developing the Codeagram app and strengthen your understanding of React basics and component thinking.

By the end of the workday, you should have made further progress on the app, applied for the GitHub Student Developer Pack, and continued with the self-study material or the CodeDex React course if needed.

---

### What To Do

1. **Apply for the GitHub Student Developer Pack** so you are ready for later sessions.

2. **Continue working on the Codeagram app**
   - Use the Codeagram app from the lesson as your main practical exercise.
   - Keep working with components, JSX, props, state and events.
3. **Refine your component structure**
   - Look at your code and decide what should stay inside one component and what should be split into smaller reusable parts.
   - Keep improving naming, structure and reuse.
4. **Use the self-study guide if you need more support**
   - If HTML, CSS or JavaScript still feel shaky, keep working through the self-study guide:
     https://www.notion.so/Self-study-with-CodeDex-io-350bc239db1180af9beacc9a801f863a
5. **Continue with the CodeDex React course**
   - Move on with the React course here:
     https://www.codedex.io/react
